Memory and devices

Real-time jobs run first and are never suspended. User jobs run in three feedback queues with a 1 second turn and move down one queue after each turn. A job leaves the user queue only when its memory and all its devices are free. Aging stops long jobs from starving: a job that has waited in queue 1 or 2 for the set number of seconds is put back at the end of queue 0.
